# overheaduas.com

Website for Overhead UAS — aerial photography, video, aerial roof inspections, mapping, and property surveillance in North County San Diego.

Static site hosted on GitHub Pages with the custom domain `overheaduas.com` (see `CNAME`).

- `index.html` — the whole site (styles and scripts inline; logo embedded)
- `images/` — gallery and banner photos (resized, location data removed)
- To change the phone number, edit `const PHONE` near the bottom of `index.html`.
